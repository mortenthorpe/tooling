# Stopwatch - Large display, for e.g. monitoring durations #
I use this for at-a-distant-glance of the computer-screen to monitor my time-expenditure while focusing on time-limited tasks, where timing is critical, e.g. for my case, for keeping me alert to my timespend while needing to record selfie-videos.

Provides a HTML/JS page, as one file, executable locally, without need to place on a Webserver, amounting to a digital display of elapsed seconds as a configurable stopwatch.

### Configurations include###
  - Timer can act as a stopwatch, counting UP - OR as a count-down, configurable on-page by a single checkbox toggle.
  - Full duration in seconds
  - Up to 5 seconds-offsets (timings) where the timer flashes and pulsates to show that within a certain "Pulse Window" (in full seconds values), the timer has reached each of the 5 interval markings "Pulse at [1-5]" and exceeded it with the pulse window.
  - Start and Reset buttons are provided
  - Start can be initiated using a single press of the leyboard spacebarre
  - Default initial values for a 120 second stopwatch duration, with default 5 Pulsetimings set at useful values for my personal taste, as well as a default 2 second Pulse Window.
